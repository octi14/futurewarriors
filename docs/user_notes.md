# más ideas

- agregar modificadores: velocidad de ataque +% (podría portarlo cualquier item, reemplazar por el velocidad de ataque existente y si es necesario setear un default para el personaje), stun chance % (armas), posibilidad de golpe crítico (más daño), hp regen +% o -% (por ejemplo, algun item podría dar un gran bonus a costa de perder un poco de hp regen, por eso coloqué el negativo), energy regen +% o -%, energía max +% o -%.
- Todos los elementos que no son amuletos y anillos, por muy poco que sea, deben tener armadura (excepto armas)
- que haya un poco más de brecha de calidad de bonuses entre los diferentes niveles de rareza. particularmente los items vulgares deben ser bastante peores que ahora, asimismo los comunes y los regulares. tampoco tiene que haber un salto gigante de regulares a uncommon, debe suavizarse la cadena completa. puede subir el gap entre una calidad y la otra para las últimas 3 rarities, si se desea.
- que cada item se llame como se tiene que llamar (a las esgrimas por ejemplo se le está dando el nombre Espada)
- restricción de colores para algunos items: no tiene sentido que un tacho de basura sea fucsia. siempre es color aluminio. eso mismo sucede con algunas otras cosas (puerta chica, martillo, tijeras, y algunas otras fueron identificadas con este problema)
