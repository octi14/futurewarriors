# Future Warriors — Fase 0

Prototipo local 1 jugador: locomoción isométrica, combate vs IA, espadas procedurales y loot.

## Correr

```bash
npm install
npm run dev
```

- Juego: http://localhost:5173/
- Preview 360 del personaje: http://localhost:5173/preview.html

## Controles

- **Mouse** — mirar
- **WASD** — mover absoluto en el mapa
- **Click / Espacio** — atacar
- **I** — inventario Diablo (paper doll + almacenamiento 40)
- **E** — recoger loot cercano
